# Bellavista Alto — Parque Libertad

## Idea inicial
Crear un sitio web informativo para el barrio Bellavista Alto, en Cuenca, Ecuador, tomando como punto central al Parque Libertad y a la sala comunal del barrio.

## Objetivos
- Destacar la identidad del barrio.
- Mejorar la comunicación comunitaria.
- Publicar noticias, avisos y eventos.
- Permitir reservas de la sala comunal sin backend.
- Hacer que el sitio funcione fácil desde GitHub Pages.

## Enfoque elegido
**Sitio informativo + WhatsApp**

La web no guarda reservas en una base de datos. En cambio, el usuario llena un formulario y el sitio arma automáticamente un mensaje de WhatsApp con todos los datos para enviar la solicitud de reserva.

## Ideas y sugerencias iniciales
- Home con identidad del barrio y del Parque Libertad.
- Sección de noticias y avisos.
- Calendario de eventos.
- Información de la sala comunal.
- Botón de WhatsApp para consultas y reservas.
- Directorio básico de contactos barriales.
- Galería de fotos del barrio.
- Mapa con puntos de interés.
- Formulario simple de sugerencias para vecinos.
- Diseño mobile-first para uso desde celular.

## Beneficios de este enfoque
- Bajo costo.
- Sin backend.
- Fácil de publicar en GitHub Pages.
- Rápido de mantener.
- Perfecto para validar si el barrio realmente lo usa.
